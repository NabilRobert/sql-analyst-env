# Results

Generated by `uv run analyst-env results` from the run records in `runs/`; a test fails if this file drifts from them. How the numbers are made: [the guide](docs/guide.md#baselines).

| Model | Tasks | Pass@1 (95% interval) | pass^5 | Mean reward | Submitted | Unsafe attempt | Costly refusal | Errored | Median time |
|---|---|---|---|---|---|---|---|---|---|

- **Pass@1:** the share of tries whose submitted query is right on both data copies, averaged per task. **pass^5:** tasks right on all five tries.
- **Mean reward** adds the penalties: -0.5 for a query refused as unsafe, up to -0.1 for queries refused for cost or timed out.
- **Submitted:** tries that called `submit_answer`; an answer given only in text scores 0. **Errored** tries (an infrastructure failure) are left out of every other column.
- The held-out tasks aren't published, so their row can't be rerun by others. Pagila's schema is public and these models have likely seen it; the data copies defeat memorised answers, not knowledge of the schema.
